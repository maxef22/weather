🌤️ Weather Add-on

version 1.2.0

Источник данных: аддон работает через погодной сервис WeatherAPI.com (по умолчанию; в коде предусмотрен также Visual Crossing).

Нужен API-ключ. Зарегистрируйтесь на сайте сервиса, скопируйте ключ в личном кабинете (Account → API Keys) и вставьте его в Настройках аддона.

Ключ хранится в конфигурации на сервере WebCTRL и не входит в состав аддона. На бесплатном тарифе WeatherAPI доступен прогноз на 3 дня — аддон запрашивает именно столько.
